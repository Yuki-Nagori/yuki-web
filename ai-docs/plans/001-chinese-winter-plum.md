# 001 · 中国古风：朱墙冬梅

状态：首版已实现。

## 原始想法

第一个风格是中国古风，以朱红色为主色调。朱红色的墙有类似故宫的感觉，场景为冬天与梅花。画面需要符合这句话的意境：

> 在坚冰还盖着北海的时候，我看到了怒放的梅花。

## 意境

寒冬仍在，冰面尚未消融，梅花已经盛放。画面同时保留冬日的清冷、朱墙的厚重和梅花的生命力：静的环境中，花成为最鲜活的部分。

宫墙提供建筑感与大面积主色，冰雪表现时节，梅花承接情绪。北海的坚冰可以通过远景或淡淡的冰面色块暗示，不必在同一画面里堆满所有元素。

## 视觉方向（设计建议）

### 场景与构图

- 大面积朱红宫墙构成主背景，保留细微墙面纹理与冬日侧光。
- 上沿或一侧露出少量覆雪檐线，暗示宫殿尺度与冬季环境。
- 梅枝从画面一侧斜伸进入，枝干有自然转折，盛开的花与花苞疏密相间。
- 主体花朵落在朱墙前，通过明暗和色差与墙体区分。
- 留出安静的题字区域，承载原句；桌面可尝试竖排，小屏优先保证完整可读。
- 冰雪与远景克制出现，避免削弱朱墙和梅花的主次关系。

### 配色

下列色值为首版尝试，实际画面再调整：

| 色彩   | 建议色值  | 用途                     |
| ------ | --------- | ------------------------ |
| 朱红   | `#A6322D` | 宫墙与主色               |
| 深绛   | `#632523` | 墙体阴影、深色层次       |
| 雪白   | `#F4F0E8` | 积雪、留白、题字         |
| 梅粉   | `#E7B4BB` | 花瓣高光，与朱墙拉开层次 |
| 墨褐   | `#342B29` | 梅枝、正文与线条         |
| 冰青灰 | `#BCCBD0` | 坚冰与冬日远景           |

### 字体与质感

题字采用有中文衬线气质的字体，正文保持清晰易读。书法字体只在少量标题或印章中尝试，字体素材确认可用许可后再引入。

墙体、雪、枝干与花瓣的质感统一，避免照片与明显不同风格的插画直接拼接。宫墙参考故宫的色彩与建筑气质，具体素材和绘制方式在实现阶段确定。

## 配套组件库（首版方向）

模块计划放在 `src/showcases/chinese-winter-plum/`。

- 场景组件：朱墙背景、梅枝装饰、雪景层、题字区。
- UI 组件：朱红或印章式按钮、纸感卡片、细线分隔、风格标题。
- 主题变量：宫墙色、花色、文字色、字体、间距与交互状态。

首页屏幕以意境为中心，组件库的完整展示可放入后续独立示例页。

## 动效与交互（设计建议）

题字可缓慢淡入，少量雪粒或梅枝微动增强冬日氛围；避免持续大幅运动。按钮与链接提供清晰的悬停和键盘焦点状态。用户开启减少动态效果时，保留完整静态画面。

## 首版范围

1. 完成桌面与手机的一屏构图：朱墙、冬景、梅花和原句。
2. 提取该风格的场景组件、基础 UI 组件及主题变量。
3. 接入首页展示序列，验证样式不会影响其他风格和网站 footer。
4. 在静态画面成立后，再补充轻量动画与独立组件展示。

验收重点是朱红墙体与盛放梅花的辨识度、寒冬与生命力并存的意境，以及模块可以独立维护。

## 首版实现与确认

- 场景使用 HTML + CSS 绘制，不使用背景图片；`winter-wall.jpg` 已移除。
- 窗户采用方形木窗，四角为内凹圆弧，内部保留传统窗棂与冰青色远景。
- 朱墙、积雪、梅枝、五瓣梅花、雪粒和题字拆分为模块内组件。
- 配套 UI 包含印章式按钮、纸感卡片和细线分隔，在“风格小集”中展示。
- 首页通过 `src/showcases/registry.ts` 登记风格；网站 Logo 与 footer 保留。
- 小屏调整窗与梅枝的位置；减少动态效果时关闭入场动画与飘雪。
- Logo 继续使用此前确认的图标资源；HTML + CSS 的要求用于本屏场景。

## 视觉与交互补充

- 参考用户提供的朱墙花窗图：舒展的五瓣白梅、细花蕊、成簇枝条，以及近景花朵的景深。
- 色调同时呼应已确认的 Logo，保持朱红与暖雪白。
- 梅枝与窗是独立场景组件；梅枝从右上方伸入，窗户保留四角内凹的方形轮廓与回纹窗棂。
- 窗内表现冬湖、薄雪远岸、冰面霜纹与淡雾。
- 屋檐由瓦面、瓦当与檐梁构成；根据最新反馈移除底部石质基座、雪线与“向下漫游”入口。
- 网站导航放在展示区外，使用独立的简洁样式。
- 鼠标在展示区移动时生成少量淡色花瓣，下落后自动清理；触屏与减少动态效果时不生成。

## 梅枝最终方向

以用户最新确认的 Logo 局部图为准：雪白枝干、舒展的五瓣花，以及朱红线状花蕊和圆点。梅枝与梅花采用这一统一图形语言，移除前一版的树皮纹理、花瓣细纹和密集花蕊。屋檐、木窗与冬湖保留各自的材质层次，梅枝仍是独立前景组件。

## 展示区整体统一

整体视觉以 `public/brand/logo-source.png`
为准，统一为朱红底与雪白轮廓。窗框、回纹、屋檐、冬湖、梅枝及配套 UI 均使用这套写意语言，移除木纹、砖缝、金属高光与强阴影。湖景用少量岸线和冰面弧线表现，梅花减少数量、增加留白，鼠标落梅保持淡色。网站导航与 footer 继续位于风格展示区之外。
